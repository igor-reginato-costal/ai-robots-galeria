# AI Robot Galeria

Galeria estática dos AI Robots, publicada como a página inicial do site.

## Source

`AI_ROBOTS_Galeria.html`

O arquivo-fonte permanece na pasta local do Google Drive. A cópia publicada no
repositório é `index.html`.

## Publication flow

Google Drive local source
→ `sync-and-push.ps1`
→ `index.html`
→ Git
→ GitHub
→ Netlify

Para publicar uma nova versão, execute `PUBLICAR_GALERIA.cmd`.
